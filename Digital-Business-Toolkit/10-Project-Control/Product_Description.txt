ContractorOS — Project Execution Dashboard
==============================================

WHAT IT IS
A task-level project execution tracker — break a project into tasks,
assign owners and due dates, and see automatically what's overdue and
how much of the project is done.

WHO IT'S FOR
Contractors managing projects with multiple stages, subcontractors, or
crew members responsible for different parts of the job.

THE PROBLEM IT SOLVES
Tasks that quietly slip past their due date because no one is tracking
the full task list against the calendar in one place.

WHAT'S INSIDE
- Main Workspace: one row per task — ID, name, category, owner, start
  date, due date, status, completion %, priority
- Automatic "days remaining" calculation (negative = overdue)
- Dashboard with live KPIs: total tasks, completed, in progress,
  overdue, overall project completion %, nearest deadline
- Color-coded status and urgency, Business Insights alerts
- Full Hebrew RTL interface, Quick Start guide, full User Guide with FAQ

HOW IT WORKS
1. Break the project into tasks with an owner and a due date each.
2. Update status and completion % as work progresses.
3. Days remaining calculates automatically — and turns red once overdue.
4. The Dashboard shows overall project health at a glance.

COMPATIBILITY
Excel 2016+ (Windows/Mac), Excel Online, Google Sheets. No macros required.

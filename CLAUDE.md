# Instagram skills

The `ig-*` skills in `.claude/skills/` come from
https://github.com/Jakeschincariol/instagram-agent-skill (MIT).

In this repo, wherever a skill says `~/.claude/instagram/` (voice.md, plan.md,
swipe.md, log.md), use `.claude/instagram/` at the repo root instead, so the
files are committed and survive between sessions.
